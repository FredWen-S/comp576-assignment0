## Tasks

1. Install Anaconda and run `conda info`.
2. Run every Python command in the *Linear Algebra Equivalents* table of
   [NumPy for MATLAB users](https://numpy.org/doc/stable/user/numpy-for-matlab-users.html).
3. Run the given Matplotlib program.
4. Make a Matplotlib figure of my own.
5. Provide a GitHub account.
6. Create a public project, commit it with Git and push it to GitHub.

## How to run

```bash
conda activate base
jupyter notebook assignment0.ipynb
```

Requires `numpy`, `scipy` and `matplotlib` (all included in Anaconda).
